# Ahmed Dorra: AI Engineer

I build LLM applications end to end (RAG, tool-using agents, evaluation, serving and monitoring) and measure whether each change works. Based in Giza, Egypt; native Arabic speaker; open to relocation and remote work. I also teach Computer Science to 700+ students and mentor learners in the MLOps MENA community.

## Projects

| Project | What it shows | Headline result |
|---|---|---|
| [**Shopping Assistant**](https://github.com/AhmedMostafa167/Shopping-Assistant) | LangGraph agent with hybrid RAG and long-term memory over 12,730 products, with evaluation, guardrails and monitoring | Agent task success 7 to 12 of 12; right product ranked first 23% to 43% |
| [**Arabic Banking Intent Classifier**](https://github.com/AhmedMostafa167/arabic_banking_intent) | Fine-tuned AraBERT, MLflow registry with promotion gates, ONNX serving, Prometheus/Grafana drift alert ([model](https://huggingface.co/Ahmed167/arabert-arbanking77-intents)) | Macro-F1 0.919 vs 0.887 baseline; image 2.26 to 0.95 GB |
| [**Research Assistant**](https://github.com/AhmedMostafa167/research-assistant) | Self-correcting agentic RAG over arXiv and the web ([live demo](https://huggingface.co/spaces/Ahmed167/research_assistant)) | Query rewriting, relevance grading, cited answers, bounded reflection |
| [**VISIONEER**](https://huggingface.co/Ahmed167/visioneer-v2) | LoRA fine-tuned Stable Diffusion for text-to-floor-plan generation, done with a colleague ([paper](https://mgv.sggw.edu.pl/article/view/10294)) | Published in Machine Graphics & Vision (2025) |
